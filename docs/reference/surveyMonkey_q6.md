# surveyMonkey_q6

Vraag en antwoorden van respondenten op vraag 6 van de survey Monkey
bevraging, uitgevoerd in het kader van WP3 van het Big picture project.

## Usage

``` r
surveyMonkey_q6
```

## Format

### `surveyMonkey_q6`

Een data frame met 1287 rijen en 5 kolommen:

- respondent_id:

  Unieke ID per respondent

- question:

  Beschrijving van de vraag

- topic:

  Beschrijving van het onderwerp van de vraag

- response:

  Beschrijving van het antwoord op de vraag

- score:

  De score op Likert-schaal die overenkomt met het antwoord op de vraag
